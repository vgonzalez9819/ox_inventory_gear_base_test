# Gear System

This resource adds a modular equipment system that allows defining existing inventory items as gear which provide player stats when equipped. It supports ESX and QBCore automatically and can integrate with either **ox_inventory** or **qb-inventory** via a simple inventory bridge.

Use `/gear` to open the equipment panel or configure it to open when the inventory UI opens. All gear, rarities, UI colors and debug tools are controlled from `config.lua`.
